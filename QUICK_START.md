# ⚡ Quick Start Guide

## Snelste manier om te starten:

### 1. Zorg dat je Node.js hebt
Download van: https://nodejs.org/ (versie 16 of hoger)

### 2. Open terminal/command prompt in deze folder

### 3. Run deze commando's:

```bash
# Installeer dependencies
npm install

# Start de app!
npm run dev
```

### 4. Open je browser
Open op deze computer:

```text
http://localhost:3000
```

Open op telefoon/tablet/laptop in hetzelfde wifi-netwerk:

```text
http://192.168.1.79:3000
```

Als je netwerkadres verandert, kijk dan in de terminal bij `Network:`.
