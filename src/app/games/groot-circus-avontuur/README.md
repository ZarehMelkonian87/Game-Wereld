# Groot Circus-Avontuur

Tweede woordenschatgame: dezelfde gameplay als Magisch Strand-Avontuur, met een circuswereld en negentien eigen woorden.

> **Status: in aanbouw.** De game staat in de catalogus als "Binnenkort beschikbaar" (`releaseStatus: "coming-soon"` in `manifest.ts`): de kaart is vergrendeld en een deep link toont het binnenkort-scherm.
