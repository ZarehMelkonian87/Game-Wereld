Tweede woordenschatgame, met een circusthema en dezelfde modi-opzet als Magisch Strand-Avontuur.

Wordt deze game opgepakt, dan verdient hij een eigen dossier in dezelfde opzet als [`docs/magisch-strand-avontuur/`](../../../../docs/magisch-strand-avontuur/GDD-index.md).
