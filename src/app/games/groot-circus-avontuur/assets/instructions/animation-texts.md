# Animatie Teksten Voor Instructievideo's — Groot Circus-Avontuur

Alle teksten die als korte animatievideo met voice-over gemaakt kunnen worden.
Plaats de MP4-bestanden in deze map. Zolang een MP4 nog niet bestaat, valt de game
automatisch terug op de spraaksynthese-stem (TTS) — je kunt dus incrementeel toevoegen.

## Productieregels

- Korte clips van ongeveer 2 tot 5 seconden.
- Rustige, duidelijke Nederlandse uitspraak.
- Bestandsnamen in kebab-case, zonder spaties.
- Koppel een video pas in de code (`asset-urls.ts`) wanneer het MP4-bestand echt bestaat.

## Video's koppelen in de code

Zodra een MP4 klaar is, koppel je die in
[`asset-urls.ts`](../../asset-urls.ts) via de betreffende getter
(`getInstructionVideoUrl`, `getSeekObjectHintVideoUrl`,
`getHighlightedObjectHintVideoUrl`, `getConceptHintVideoUrl`,
`getFeedbackVideoUrl`, `sharedPlaceHintVideoUrl`). Deze geven nu bewust
`undefined` terug, waardoor de game terugvalt op de spraaksynthese-stem.
