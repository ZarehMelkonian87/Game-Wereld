# Concept Art

Deze map is voor de visuele richting van `+1 Woordenschat Bezem Escape`.

Voordat nieuwe gameplay of UI wordt gebouwd, moet hier eerst duidelijk zijn:

- hoe de gamewereld eruitziet;
- welke visuele stijl de objecten krijgen;
- hoe knoppen, tabs en menu's eruitzien;
- welke kleuren wel en niet gebruikt worden;
- welke regels gelden voor mobiele schermen;
- hoe de game aansluit op de bestaande Game Wereld app-stijl.

## Bestanden

- `art-direction-bible.md` - complete art direction bible voor alle game-assets.
- `style-prompt.md` - vaste stijlprompt voor alle gegenereerde afbeeldingen.
- `ui-mockups.md` - mobiele UI mockup-richting voor alle hoofdschermen.
- `visual-direction.md` - visuele richting voor wereld, sfeer, kleuren en objecten.
- `ui-rules.md` - harde regels voor menu's, tabs, knoppen, panels en mobiele layout.
- `generated-images/` - bewaarde gegenereerde concept-afbeeldingen.

## Belangrijke Afspraak

Alle UI-elementen moeten de bestaande app-stijl volgen. Er mogen geen losse, willekeurige knoppen, tabs, menus of panels worden toegevoegd met een andere stijl.

Als een nieuw scherm of component nodig is, moet eerst worden bepaald:

1. Welke bestaande app-stijl het volgt.
2. Welke kleurvariant hoort bij deze game.
3. Hoe het werkt in portrait en landscape.
4. Welke touch target-regels gelden.
5. Hoe tekst en iconen binnen de knop blijven passen.
