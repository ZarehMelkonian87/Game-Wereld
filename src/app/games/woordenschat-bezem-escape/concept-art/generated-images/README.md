## Source Prompts

### Star Mascot Character Sheet

```text
Design a friendly mascot for a mobile educational children's game called '+1 Woordenschat Bezem Escape'. A cute talking star mascot with a smiling face, small arms, and a magical sparkle trail. The mascot helps the child with vocabulary, gives hints, and celebrates correct answers. Create a clean mascot sheet with multiple versions arranged on one sheet without text labels: neutral pose, happy pose, thinking pose, pointing pose, celebration pose, hint-giving pose, and a small icon version for UI. The mascot must feel safe, kind, supportive, calm and encouraging. Soft pastel yellow and warm colors. 2D digital sticker illustration for a mobile educational children's game, paper cut-out style, thick rounded black outline, soft pastel colors, simple readable shapes, white sticker border, child-friendly, clean design, high contrast, preschool learning game style, no text, no watermark, no logo, no photorealism, no scary details, centered composition.
```

### Magical Broom Set

```text
Design a magical broom set for a mobile educational children's game called '+1 Woordenschat Bezem Escape'. The brooms are cute, safe, soft and child-friendly, used by a child avatar to fly through vocabulary worlds, magical but not scary. Create a clean asset sheet without text labels showing: basic wooden beginner broom, beach broom with shells and blue ribbons, dolphin broom, rainbow broom, star broom, super speed broom. Each broom should be clearly different but belong to the same visual style. Also include small icon versions for each broom for a shop or reward screen. 2D digital sticker illustration for a mobile educational children's game, paper cut-out style, thick rounded black outline, soft pastel colors, simple readable shapes, white sticker border, child-friendly, clean design, high contrast, preschool learning game style, no text, no watermark, no logo, no photorealism, no scary details, centered composition.
```

### Beach Scene Board Backgrounds

```text
Create two clean empty beach scene backgrounds for a mobile educational children's game, shown as a side-by-side concept sheet: one landscape mobile screen version and one portrait mobile screen version. The backgrounds are scene boards where children drag and place sticker objects. Calm beach with sky, sea, gentle waves, sand, and a small island area. Clear zones: sky zone, sea zone, beach/sand zone, island zone, left/middle/right areas implied by layout. 2D pastel children's illustration, soft colors, paper scene board style, simple shapes, no characters, no foreground learning objects, no dolphin, no boat, no lighthouse, no ball, no parasol, no shells, no crab, no text, no logo. Clean and not too detailed, lots of empty space for draggable sticker objects. Mobile educational preschool game style, warm safe atmosphere, no photorealism, no scary details.
```

The original generated image contains both versions on one sheet. The separate landscape and portrait files were cropped from that sheet for easier future use.
