# Schelpen Tellen

Status: beschikbaar  
Inhoudelijk eigenaar: repository-/producteigenaar  
Contentversie: `rekenen-strand-2026.07`

## Leerdoel

Het kind koppelt een zichtbare hoeveelheid van één tot en met vijf aan het bijbehorende cijfer. Iedere hoeveelheid komt exact één keer voor. De game doet geen diagnostische uitspraak; zij registreert alleen observeerbare pogingen.

## Oefencontract

- skill: `number-quantity-1-5`;
- taken: `tel-1` tot en met `tel-5`;
- outcome: correct/incorrect;
- responstijd: via de runtimeklok;
- hulp: leeg, omdat deze versie geen inhoudelijke hint geeft.

## Toegankelijkheid

Iedere hoeveelheid heeft zowel emoji's als de tekstuele toegankelijke naam “Er liggen N schelpen”. Antwoorden zijn native knoppen van minimaal 48 px. De kernflow vereist geen kleuronderscheid, geluid, microfoon, drag, hover, animatiesnelheid of tijdslimiet.

## Offline

`rekenen-strand-basis-v1` bevat de gehashte lazy gamechunk. Er zijn geen externe media-assets. Het pakket wordt met dezelfde manager gecontroleerd als de strandgame.
