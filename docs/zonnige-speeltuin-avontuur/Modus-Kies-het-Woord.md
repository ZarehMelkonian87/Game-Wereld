# 🃏 Modus — Kies het Woord (Speeltuin)

> Instapmodus. **Mechanisch identiek** aan [Kies het Woord in het strandspel](../magisch-strand-avontuur/Modus-Kies-het-Woord.md): 2–4 keuzekaarten, oplopende afleiders, automatisch doorgaan na een goed antwoord, goed/fout-geluid en een ronde-eindscherm.

| Veld             | Waarde                                      |
| :--------------- | :------------------------------------------ |
| **Modus-ID**     | `MODE_KIES_WOORD` (`choose-word`)           |
| **Ontgrendeld**  | Altijd (0 ⭐)                               |
| **Talige focus** | Receptief: woordherkenning tussen afleiders |
| **Status**       | 🔵 Nog te bouwen                            |

## Speeltuin-eigen

- **14 vragen** (`cw-001` … `cw-014`) in geschudde volgorde.
- De afleiders lopen op: niveau 1 uit een andere categorie, niveau 2 uit hetzelfde thema, niveau 3 uit dezelfde categorie.
- Alle vragen staan letterlijk in de [woordenlijst](Woordenlijst.md).

## Wat er moet gebeuren

Code overnemen uit het strandspel (taak **C-04** in de [Takenlijst](Takenlijst.md)), 14 opdrachtvideo's produceren (§3.2) en de stickers als WebP aanleveren (A-01).
